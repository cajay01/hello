# Baby Animals Fun Day

A premium **15-page** coloring book (plus cover) for children ages **3–8**.

Print-ready size: **US Letter, 8.5 × 11 inches**, 300 DPI.

## Files

- `Baby-Animals-Fun-Day.pdf` — cover + 15 coloring pages, ready to print
- `pages/` — individual 8.5×11 PNG pages
- `source/` — original illustrations
- `assemble.py` — rebuilds the bordered pages and PDF

## Rebuild

```bash
pip install -r requirements.txt
python3 assemble.py
```
